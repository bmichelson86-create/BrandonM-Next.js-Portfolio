# Brandon Michelson — Portfolio (Next.js)

Rebuild of the vanilla-JS portfolio in Next.js. Separate project — the original at
`../brandon-portfolio` is untouched and still deployable.

## Running it

There is no `index.html` to open. Next.js compiles pages on request, so a server
must be running:

```bash
npm run dev      # http://localhost:3000 — use this while working, hot reloads
npm run build    # production build
npm start        # serve the production build
```

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · CSS Modules · GSAP 3 +
ScrollTrigger via `@gsap/react` · Lenis · lottie-react · lucide-react

CSS Modules rather than Tailwind: the design is a faithful port of a 3,900-line
hand-written stylesheet, and rewriting that into utility classes would have lost
detail for no gain. Design tokens live in `app/globals.css`.

## Layout

```
app/
  layout.tsx              fonts, metadata, JSON-LD, Lenis wrapper
  page.tsx                homepage composition
  globals.css             design tokens + base + shared section styles
  work/[slug]/page.tsx    one template, all five case studies
components/               one component + one .module.css each
lib/
  projects.ts             the five projects (order, media, tilt cards)
  caseStudies.ts          case-study copy
public/
  images/  video/  lottie/
```

## Editing content

Both data files are plain TypeScript — no component changes needed.

- **Reorder projects** — change the `order` field in `lib/projects.ts`.
- **Add a project** — append to the `projects` array; the homepage picks it up.
- **Background too bright/dark** — set `bgBrightness` (default `0.4`).
  Biddle-Shaw uses `0.16` because its footage comes from a white site.
- **Case-study copy** — edit `lib/caseStudies.ts`.

### Unfinished case-study copy

Sections can carry a `todo: string[]` field. It renders as an amber
**"Needs your input"** block on the page, so placeholder copy cannot ship by
accident. Answer the prompts in the surrounding `paragraphs`, then delete the
`todo` field.

Biddle-Shaw currently has three of these: The Objective, Build & Stack, and
Results & Takeaways.

## Notes

- Media is optimized: images are WebP (~1.2 MB total), videos re-encoded H.264
  (~6.5 MB total). Down from ~33 MB of source assets.
- Everything animated respects `prefers-reduced-motion`.
- The contact form posts to Web3Forms. The access key is public by design; move
  it to a Server Action if you want it out of the client bundle.
- `AGENTS.md` / `CLAUDE.md` are generated by `next dev` — leave them in place.
